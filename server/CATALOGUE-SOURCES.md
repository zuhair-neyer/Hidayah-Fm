# Devotional catalogue

`catalogue.json` contains 60 Nasheed and 60 Naat recordings. The first 12 retain the original catalogue order; 54 recordings have been added to each collection. Different performances of the same traditional text are credited to their respective artists.

The 108 additions were checked against YouTube's public oEmbed metadata on 29 October 2026. Every new source returned HTTP 200 and its title and artist were matched to the source listing. Nasheed additions primarily use Awakening Music, plus Sami Yusuf's channel. Naat additions use Owais Raza Qadri, Hafiz Tahir Qadri and Hi-Tech Islamic artist/label listings. Each entry records its exact source video ID, original source title, channel and check date.

Two original search links were resolved: **Faslon Ko Takalluf** by Owais Raza Qadri (Sabzwari Production) and **Zahe Muqaddar** by Qari Waheed Zafar Qasmi (ARY Qtv). The other eight pre-existing video sources also returned oEmbed HTTP 200. In total, 118 entries have direct source videos.

Two legacy entries remain search links and are displayed as **Find recording**: **Taweel Al Shawq — Abu Ali** and **Madine Ka Safar — Junaid Jamshed**. These exact title/artist pairings could not be verified. They were kept to preserve existing IDs and saved-library references; no different recording was silently substituted.

Recordings open through the existing YouTube source player or source link. This update does not download, rehost or extract their audio. The collection contains the artists' published versions, including instrumental arrangements; only versions explicitly titled “Vocals Only” or “Acapella” are identified as such. Metadata verification is not a guarantee of future availability, regional access or successful playback on every device.

Seeding runs in a transaction on application startup. It matches existing entries by title, artist and collection, appends missing entries, and fills empty source links or replaces the exact search URL generated by the old seed. Existing track IDs, custom recordings, artwork, metadata and play counts remain unchanged. Running it again does not add duplicates. Firebase user data is not accessed by the catalogue seed.
